## [0.1.0] - 2026-06-24

### Added
- Declarative CLI and schema validation.
- Default three-node Rocky Linux 9 RKE2 HA profile with one VIP.
- Co-located HAProxy/Keepalived role using non-conflicting frontend ports.
- HA cert-manager, approver-policy, trust-manager, optional CSI driver, and Traefik integration.
- Registry and installer coverage for twenty PKI/certificate automation tools.
- RKE2, k3s, existing-Kubernetes, standalone, Docker/Podman, raw, and Windows modes.
- GitHub and GitLab CI, security, contribution, and release scaffolding.
